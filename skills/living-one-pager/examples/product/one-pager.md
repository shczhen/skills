# Lantern API 契约工具包

**完全虚构的产品与数据示例。** Lantern 帮助维护 HTTP API 的开发者在交付变更前发现契约差异，并理解它们对现有调用方的影响。[来源](source.md)

## 用户、问题与价值

面向维护 API 的开发者。典型问题是新增或修改字段后，现有客户端可能无法继续使用。Lantern 把定义比较与差异解释放到本地工作流；减少问题的预期价值尚未经过真实用户效果验证。

## 能力与使用场景

CLI 比较 OpenAPI 定义，本地 HTML 查看器解释差异，示例契约帮助尝试。典型场景是检查修改必填字段是否影响既有客户端。JSON 报告输出也已在本地可用，可供后续 CI 用法参考；CI 示例仍是草稿。

## 怎么体验

按来源中的虚构用法，运行 `lantern compare before.yaml after.yaml`，再打开 HTML 报告。当前材料支持解释这条本地路径；它不证明所有平台或 CI 环境均可使用。

## 当前可用情况

来源确认本地 CLI、HTML 查看器和 JSON 输出可用。其他人的采用情况尚未提供。最新增加的 JSON 能力继续归在同一产品介绍中。

## 依据与反馈

一次准备好的测试环境中，6组模拟契约对完成检查，含准备步骤的完整流程中位耗时46秒。它支持对应环境的观察，不能证明真实用户效果或跨平台可靠性。手册草稿写“30秒开始检查”，计时终点及条件未说明；两个说法需澄清适用范围，暂不合并成统一承诺。[观察和手册来源](source.md#new-capability-and-observation)
